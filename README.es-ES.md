## About

Jumphigh es un juego de plataformas sencillo inspirado en Icy Tower. 
Está desarrollado utilizando c++17 y SFML.

#### Captura de pantalla:

![Screenshot](/resources/Screenshots/Screenshot.png)

## Requirements
```sh
- sfml
- g++
- make
```

## Compiling (Linux)

1. Clonar el repositorio
```sh
git clone https://github.com/4rlenrey/JumpHigh.git
```
2. Compilar 
```sh
make
```
2. Ejecutar 
```sh
./Jumphigh
```
